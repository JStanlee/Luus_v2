# Release Notes - Fixes v2.1

## Zrealizowane Poprawki

1.  **Layout (Bezpieczne strefy)**
    -   Dodano `safe-area-inset` w CSS. Aplikacja nie powinna już wchodzić pod notch/pasek statusu.

2.  **Logika Ćwiczeń (Bodyweight)**
    -   Zaktualizowano prompt AI. Ćwiczenia kalisteniczne (Pompki, Dipy) powinny teraz sugerować **0kg (BW)** i wyższy zakres powtórzeń.

3.  **Timer (Przerwy)**
    -   Naprawiono widoczność przycisków. Opcje **45s, 60s, 90s** są teraz widoczne pod timerem i pozwalają na szybką zmianę czasu.

4.  **Logo & Branding**
    -   Ponownie wgrano pliki logo i wygenerowano ikony.
    -   **Uwaga:** Jeśli ikona na pulpicie emulatora się nie zmieniła, spróbuj odinstalować aplikację i uruchomić `npx cap run android` ponownie.
